### 3.3 ExecutorRegistrar（扫描）

```java
public class ExecutorRegistrar implements SmartInitializingSingleton, ApplicationContextAware {
    @Override public void afterSingletonsInstantiated() {
        for (String name : ctx.getBeanDefinitionNames()) {
            Object bean = ctx.getBean(name);
            Class<?> clazz = AopUtils.getTargetClass(bean);
            for (Method m : clazz.getDeclaredMethods()) {
                ManagedScheduled ann = AnnotatedElementUtils.findMergedAnnotation(m, ManagedScheduled.class);
                if (ann == null) continue;
                validate(m);                                  // public 无参
                String id = ann.id().isEmpty() ? props.getAppName()+":"+name+"."+m.getName() : ann.id();
                m.setAccessible(true);
                registry.register(new JobHandler(id, bean, m, ann));
            }
        }
        adminClient.register(props.getAppName(), localAddress(), registry.all());  // HTTP 注册
        heartbeatWorker.start();                              // 启动心跳
    }
}
```

### 3.4 JobThread（执行 + 异常隔离 + 阻塞策略）

```java
public class JobThread extends Thread {
    private final BlockingQueue<TriggerParam> queue = new LinkedBlockingQueue<>();
    private volatile boolean running = true;
    private volatile boolean busy = false;
    public void push(TriggerParam p) {
        if (busy && p.getBlockStrategy()==BlockStrategy.DISCARD) { callbackDiscard(p); return; }
        if (busy && p.getBlockStrategy()==BlockStrategy.OVERRIDE) { /* 标记中断前次 */ }
        queue.offer(p);
    }
    @Override public void run() {
        while (running) {
            TriggerParam p = queue.take();
            busy = true; long start = System.currentTimeMillis(); boolean ok=false; String err=null;
            try {
                ShardingContext.set(p.getShardIndex(), p.getShardTotal());
                handler.getMethod().invoke(handler.getBean());
                ok = true;
            } catch (Throwable t) { err = rootMessage(t); log.error("job {} failed", p.getTaskId(), t); }
            finally {
                ShardingContext.clear(); busy = false;
                adminClient.callback(p.getLogId(), ok, System.currentTimeMillis()-start, err);
            }
        }
    }
    public boolean isIdle(){ return !busy && queue.isEmpty(); }
}
```

> 必须吞异常：否则线程退出，该任务后续触发全部丢失。

### 3.5 ExecutorController（接收触发）

```java
@RestController
@RequestMapping("/scheduler-executor")
public class ExecutorController {
    @PostMapping("/run")
    public ApiResult<String> run(@RequestHeader("X-Access-Token") String token, @RequestBody TriggerParam p) {
        checkToken(token);
        JobHandler h = registry.get(p.getTaskId());
        if (h == null) return ApiResult.fail("任务未注册: " + p.getTaskId());
        h.invoke(p);
        return ApiResult.ok("accepted");          // 异步受理
    }
    @PostMapping("/beat")
    public ApiResult<Boolean> beat(@RequestHeader("X-Access-Token") String token) {
        checkToken(token);
        return ApiResult.ok(registry.all().stream().allMatch(h -> h.getJobThread().isIdle()));
    }
}
```

### 4.2 AdminScheduler（到点触发）

```java
@Component
public class AdminScheduler {
    private final ThreadPoolTaskScheduler scheduler;
    private final TriggerService triggerService;
    private final AdminLeaderElection leaderElection;
    private final Map<String, ScheduledFuture<?>> futures = new ConcurrentHashMap<>();

    public synchronized void schedule(TaskConfig cfg) {
        stop(cfg.getTaskId());                       // 先取消旧触发器
        if (!cfg.isEnabled()) return;
        Runnable job = () -> runScheduled(cfg.getTaskId());
        ScheduledFuture<?> f = buildFuture(cfg, job); // CRON/FIXED_RATE/FIXED_DELAY，非法配置告警跳过
        if (f != null) futures.put(cfg.getTaskId(), f);
    }
    // HA 判主：仅 leader 真正下发；follower 空跑 standby。手动触发不经此路径
    void runScheduled(String taskId) {
        if (!leaderElection.isLeader()) return;
        triggerService.trigger(taskId, TriggerService.TYPE_SCHEDULE);
    }
    public synchronized void stop(String id) {
        ScheduledFuture<?> f = futures.remove(id);
        if (f != null) f.cancel(false);
    }
    public synchronized void reschedule(TaskConfig cfg) { if (cfg.isEnabled()) schedule(cfg); else stop(cfg.getTaskId()); }
}
```

> 启动恢复由 `AdminBootstrap`（`@EventListener(ApplicationReadyEvent)`）从 DB 加载所有 enabled 任务并 `schedule`；停止态不自动运行。

### 4.3 TriggerService（触发编排）

```java
public void trigger(String taskId, String triggerType) {   // TYPE_SCHEDULE / TYPE_MANUAL
    TaskConfig cfg = taskConfigDao.findById(taskId);
    if (cfg == null) return;
    if (TYPE_SCHEDULE.equals(triggerType) && !cfg.isEnabled()) return;
    List<ExecutorNode> nodes = executorDao.findOnlineByApp(cfg.getAppName());
    List<RouteTarget> targets = router.route(cfg.getRouteStrategy(), nodes, taskId);
    if (targets.isEmpty()) {
        if (TYPE_MANUAL.equals(triggerType)) {              // 手动触发记一条失败日志；调度触发仅告警
            long logId = logDao.insertTrigger(cfg, triggerType);
            logDao.markTriggerFail(logId, "无在线执行器实例");
        }
        alarmNotifier.onTriggerFailure(cfg, triggerType, "无在线执行器实例");
        return;
    }
    for (RouteTarget t : targets) dispatch(cfg, t, triggerType);  // 每个目标(含每片)独立一条日志
}
private void dispatch(TaskConfig cfg, RouteTarget t, String triggerType) {
    long logId = logDao.insertTrigger(cfg, triggerType);
    TriggerParam p = build(cfg, logId, t, triggerType);
    boolean accepted = false;
    for (int i = 0; i < cfg.getRetryCount() + 1 && !accepted; i++) accepted = executorClient.run(t.getAddress(), p);
    if (accepted) logDao.markTriggered(logId, t.getAddress(), t.getShardIndex(), t.getShardTotal());
    else { logDao.markTriggerFail(logId, "触发失败：执行器不可达或未受理");
           alarmNotifier.onTriggerFailure(cfg, triggerType, "触发失败：执行器不可达或未受理"); }
}
```

### 4.4 ExecutorRouter（路由策略）

```java
public interface RouteStrategyHandler { List<RouteTarget> route(List<ExecutorNode> nodes, String taskId); }

@Component public class FirstHandler implements RouteStrategyHandler {
    public List<RouteTarget> route(List<ExecutorNode> n, String id){ return List.of(new RouteTarget(n.get(0).getAddress(),0,1)); }
}
@Component public class RoundHandler implements RouteStrategyHandler {
    private final Map<String,AtomicInteger> counters = new ConcurrentHashMap<>();
    public List<RouteTarget> route(List<ExecutorNode> n, String id){
        int i = Math.abs(counters.computeIfAbsent(id,k->new AtomicInteger()).getAndIncrement() % n.size());
        return List.of(new RouteTarget(n.get(i).getAddress(),0,1));
    }
}
@Component public class ShardingBroadcastHandler implements RouteStrategyHandler {
    public List<RouteTarget> route(List<ExecutorNode> n, String id){
        List<RouteTarget> r = new ArrayList<>();
        for (int i=0;i<n.size();i++) r.add(new RouteTarget(n.get(i).getAddress(), i, n.size()));
        return r;
    }
}
@Component public class FailoverHandler implements RouteStrategyHandler {
    // 依次 executorClient.beat(addr) 探测，选首个 idle；全忙取第一个
}
// LAST / RANDOM / CONSISTENT_HASH 类似

public class ExecutorRouter {
    private final Map<RouteStrategy, RouteStrategyHandler> handlers;   // 注入聚合
    public List<RouteTarget> route(RouteStrategy s, List<ExecutorNode> n, String id){ return handlers.get(s).route(n,id); }
}
```

### 6.3 控制台 → 调度中心

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/tasks?appName=&keyword=&group=&enabled=` | 列表（服务端过滤） |
| GET | `/api/tasks/{id}` | 详情 |
| PUT | `/api/tasks/{id}/schedule?version=` | 改周期 `{type,cron,fixedRate,fixedDelay,initialDelay}` |
| PUT | `/api/tasks/{id}/route?version=` | 改策略 `{routeStrategy,blockStrategy,retryCount}` |
| POST | `/api/tasks/{id}/start?version=` `/stop?version=` | 启停（乐观锁） |
| POST | `/api/tasks/{id}/trigger` | 执行一次（无需 version） |
| GET | `/api/executors?appName=` | 执行器注册表 |
| GET | `/api/tasks/{id}/logs?limit=&offset=` | 日志 |

统一响应 `{code,message,data}`，code=0 成功；业务校验/冲突 HTTP 400 + `{code:40000,message:...}`（如"Cron 表达式不合法""配置已被他人修改，请刷新后重试"）；令牌非法 HTTP 401 + `{code:40100}`。写操作以查询参数 `version` 做乐观锁，服务端 `WHERE version=?` 更新并自增。管理 API（`/api/tasks/**`、`/api/executors/**`）经 `ManagementAuthInterceptor` 令牌校验（默认开启）。

## 7. 校验与异常

```java
public static void validate(UpdateScheduleRequest r) {
    switch (r.getType()) {
        case CRON: if(!CronExpression.isValidExpression(r.getCron())) throw new ScheduleException("Cron 表达式不合法"); break;
        case FIXED_RATE: if(r.getFixedRate()==null||r.getFixedRate()<MIN_MS) throw new ScheduleException("固定频率需 ≥ "+MIN_MS+"ms"); break;
        case FIXED_DELAY: if(r.getFixedDelay()==null||r.getFixedDelay()<MIN_MS) throw new ScheduleException("固定延迟需 ≥ "+MIN_MS+"ms"); break;
    }
}
```

- `ScheduleException` → `@RestControllerAdvice`（`ScheduleExceptionHandler`）转 HTTP 400 + `ApiResult.fail(40000,...)`；缺参/非法 JSON/类型错误同样 400。
- accessToken 校验失败 → 401（`TokenInterceptor` 拦截 `/api/registry/**`、`/api/log/**`）。
- 管理 API 鉴权失败 → 401（`ManagementAuthInterceptor` 拦截 `/api/tasks/**`、`/api/executors/**`，`management-auth-enabled` 默认 true，令牌取 `management-token`，空则回退 `accessToken`）。
- 任务执行异常仅在 JobThread 内捕获回调，不进 web 异常链。

## 9. 关键时序

### 注册
```
业务服务启动 → ExecutorRegistrar 扫描 → JobHandlerRegistry
 → AdminClient.register → admin RegistryService
    → upsert sched_executor → 新任务 insert sched_task → AdminScheduler.schedule
 → HeartbeatWorker 周期 beat
```
### 触发（FAILOVER）
```
AdminScheduler 到点 → TriggerService.trigger
 → onlineNodes(app) → FailoverHandler 探测 beat 选 idle
 → logDao.insertTrigger → ExecutorClient.run(addr, TriggerParam)
 → 执行器 JobThread 执行 → AdminClient.callback(logId,result) → logDao 更新
```
### 改周期
```
控制台 PUT schedule → TaskService 校验 → DB update(version+1)
 → AdminScheduler.schedule(取消旧/建新) → 返回 TaskView（执行器无感）
```

## 11. Boot 2.7 / JDK 8 兼容

- `CronExpression`（Spring 5.3+）；老版用 `CronSequenceGenerator`。
- `scheduleAtFixedRate(Runnable, Instant, long)` Spring 5.3+；老版用 `Date`。
- 自动装配：Boot 2.x 用 `spring.factories`，`@AutoConfiguration`→`@Configuration`。
- JDK 8 避免 record/switch 表达式/`List.of`（用 `Arrays.asList`/`Collections.singletonList`）。
- HTTP 客户端：可用 `RestTemplate`（通用）或 `RestClient`（Boot 3.2+）；执行器侧建议 RestTemplate 减少依赖。
